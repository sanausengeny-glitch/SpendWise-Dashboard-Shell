SpendWise Dashboard Shell
Description
SpendWise Dashboard Shell is a responsive financial dashboard layout built using HTML and CSS. It demonstrates the use of CSS Grid, Flexbox, CSS Variables, responsive design, and micro-interactions.
Features
Sidebar navigation menu
Header section
Six financial category cards
CSS Grid page layout
Flexbox for internal alignment
CSS Custom Properties (Variables)
Responsive design for mobile devices
Hover and focus animations
Dark mode support using prefers-color-scheme
Technologies Used
HTML5
CSS3
CSS Grid
Flexbox
CSS Variables
Dashboard Categories
The dashboard displays static financial information for:
Food
Transport
Rent
Entertainment
Savings
Utilities
How It Works
CSS Grid structures the overall dashboard layout.
Flexbox aligns content within the sidebar, header, and cards.
CSS Variables provide a consistent color theme.
A media query adapts the layout for screens smaller than 768px.
Hover and focus effects improve user experience.
Dark mode is supported by overriding CSS variables.
